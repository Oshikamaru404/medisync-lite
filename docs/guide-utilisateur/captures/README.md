# Captures d’écran du guide

## État actuel

Les captures marquées **réalisées** proviennent de l’application en session authentifiée. Elles ont été reprises en **pleine page** avec le zoom arrière du navigateur, sans barre de défilement verticale dans l’image. Le propriétaire de la session a confirmé que le jeu de données visible est synthétique. Les fichiers `*-safe.png` sont d’anciennes versions masquées et ne sont pas les illustrations retenues.

Les vues métier indisponibles avec les données et l’état présents (consultation active, certificat, partage ou paiement à saisir) restent **à réaliser**. Aucun rendez-vous, dossier, règlement ou document n’a été créé pour fabriquer ces captures.

## Règles de capture

- Capture de l’interface réellement exécutée, sans maquette.
- Les images actuellement retenues utilisent le jeu de démonstration déclaré synthétique par le propriétaire de la session.
- Avant chaque capture, contrôler la barre d’adresse, le profil actif et les éléments visibles.
- Ne pas réutiliser ces images si la session contient ultérieurement des données réelles; remplacer les données avant toute nouvelle capture.
- Ne pas confondre une donnée synthétique qui ressemble à une donnée personnelle avec une donnée réelle; conserver cette distinction dans les légendes.
- Préférer une capture nette par fonction; annoter en français dans le texte autour, et non par des flèches décoratives superposées qui masquent l’interface.
- Les captures retenues sont des PNG pleine page. Les anciennes versions viewport et masquées restent dans le dossier à titre de traces, mais ne sont pas référencées ci-dessous.
- Donner un texte alternatif descriptif et une légende qui explique ce qu’il faut regarder.
