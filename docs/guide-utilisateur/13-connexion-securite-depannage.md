# 14. Connexion, sécurité et dépannage

## Connexion et profils

### « Impossible de charger les profils »

1. Vérifiez que l’appareil a accès au réseau.
2. Actualisez la page ou utilisez **Réessayer** si le bouton est proposé.
3. Si l’erreur persiste, contactez l’administrateur du cabinet.

Ne saisissez pas le PIN dans une autre page et ne partagez pas vos identifiants.

### PIN refusé ou session verrouillée

Vérifiez la saisie. Après verrouillage, utilisez le processus prévu par le cabinet pour récupérer l’accès. Ne demandez pas à un collègue de vous communiquer son PIN.

## Protéger les données du patient

- Verrouillez la session quand vous vous éloignez du poste.
- Ne laissez pas un dossier patient ouvert sur un écran visible du public.
- Utilisez uniquement le partage de documents prévu dans l’application.
- Limitez les exports aux informations nécessaires et protégez-les comme des dossiers médicaux.
- Ne copiez pas des données de santé réelles dans des captures, tickets de support ou documents d’aide.
- Avant de supprimer ou modifier un dossier, vérifiez l’identité et les conséquences de l’action.

## Erreur de sauvegarde ou réseau

1. Ne fermez pas immédiatement l’écran concerné.
2. Notez le message exact sans copier de données patient dans un canal non sécurisé.
3. Vérifiez si l’objet est déjà apparu dans la liste/historique pour éviter un doublon.
4. Réessayez après rétablissement réseau uniquement si l’état n’a pas déjà été enregistré.
5. Si l’échec continue, sollicitez le responsable avec l’heure, le module et l’action (sans données médicales superflues).

Le mode hors ligne n’est pas garanti. N’interprétez pas une page déjà affichée comme preuve que les modifications seront synchronisées.

## Problèmes d’impression

- Vérifiez le format choisi dans Shifalyx et le papier réellement chargé.
- Dans la boîte d’impression native, sélectionnez l’imprimante; le navigateur ne fournit pas toujours un choix persistant de périphérique.
- Vérifiez l’orientation, les marges et l’échelle. Le mode « Ajuster à la page » peut modifier les dimensions.
- Faites un test avec l’ordonnance de démonstration avant un lot de documents.
- En cas de décalage, vérifiez les paramètres du pilote d’imprimante et le format papier sélectionné.

## Informations à transmettre au support

Décrivez le module, l’étape, l’heure approximative, le navigateur/appareil et le texte d’erreur. Masquez les identifiants et n’incluez ni ordonnance réelle, ni nom de patient, ni téléphone, ni contenu clinique dans une capture non sécurisée.
